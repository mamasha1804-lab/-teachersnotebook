# English Teacher Planner

Автономная версия ежедневника учителя, подготовленная для дальнейшего размещения на GitHub.

## Что реализовано

- «Сегодня» показывает уроки текущего дня из единого расписания.
- Изменения в «Моём расписании» сразу используются в «Сегодня» и в недельной сетке.
- Дата и день недели определяются автоматически по московской дате.
- Объёмная пастельно-розовая кнопка «Добавить урок» с отдельным 3D-плюсом.
- На главной: расширенные «Мои блестящие идеи», «План на день», «Трекер платных занятий».
- «План на день»: выполнено / время 06:00–23:00 с шагом 30 минут / текст задачи. План хранится отдельно для каждой даты.
- Раздел «Платные занятия» вместо раздела «Уроки» в боковом меню.
- Трекер платных занятий: ребёнок, класс, ФИО родителя, телефон, срок оплаты, отметка оплаты.
- Четыре фильтра трекера: всего детей, оплачено, не оплачено, просрочено. По нажатию открывается соответствующий список.
- Просрочка определяется автоматически: если срок прошёл и оплата не отмечена.
- Верхняя медиапанель: ссылка или локальный файл, изменение размера, полноэкранный режим для проектора.
- Подсказка: «Прикрепи файл или ссылку чтобы вывести на экран».
- Пастельно-розовая палитра вместо коралловой.
- Вход по логину и паролю; при создании доступа вводится имя учителя, которое появляется в приветствии.
- Декоративные сердечки и звёздочки со звуком «дзынь» при нажатии.
- Отдельные локальные SVG-иконки для списка учеников, идей и плана на день.

## Запуск

Самый простой вариант:

1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. При первом запуске выберите «Создать доступ», укажите имя учителя, логин и пароль.

Для локального сервера:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Хранение данных

Сейчас проект полностью статический и сохраняет данные в `localStorage` браузера. Это удобно для локальной проверки и GitHub Pages, но такая авторизация не является серверной защитой. Для настоящего защищённого входа на публичном сайте следующим этапом стоит подключить Supabase/Firebase/Auth0 или собственный backend.

Локально поддерживаются несколько учительских аккаунтов в одном браузере: данные каждого логина хранятся отдельно.

## Медиапанель

Можно:

- вставить ссылку на страницу/видео;
- прикрепить локальный файл;
- открыть PDF, изображения, видео, аудио и форматы, которые умеет показывать браузер;
- изменить размер панели мышью за нижний правый угол;
- включить полноэкранный режим кнопкой `⛶`.

Локальный файл выбирается заново после полного закрытия страницы, потому что браузер не разрешает веб-странице постоянно хранить произвольный путь к файлу на компьютере.

## GitHub Pages

Проект состоит из обычных статических файлов, поэтому его можно загрузить в GitHub-репозиторий и включить GitHub Pages. Перед публичным запуском рекомендуется заменить локальную авторизацию на серверную.
